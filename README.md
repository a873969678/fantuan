# 饭团与紫菜

当前目标为静态漫画，暂不制作短剧。第一集《暑假片1》采用孩子手绘故事、极简风和用户指定人物。先出封面，再逐张生成八张正文；每张由用户审核后才继续。对话直接入图，使用童趣手写字体、左上角圆圈序号，并预留抖音界面遮挡空间。当前漫画规格见[项目设定](项目设定.md)，封面提示词见[图片提示词](剧集/EP001/图片提示词.md)。
